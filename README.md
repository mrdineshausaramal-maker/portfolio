## 🛠️ Key Features
- **Space Obsidian Aesthetic**: Linear / Vercel developer dark mode with dynamic light theme toggle.
- **Hero Constellation Canvas**: Ambient 60fps particle physics engine.
- **Live Code Runner & Terminal**: Simulates compilation and execution of Java, SQL, and Shell diagnostics.
- **LoadLoop Economics & Carbon Calculator**: Real-time logistics cost-sharing and CO2 offset model.
- **Command Palette (`Ctrl+K`)**: Keyboard-driven navigation across sections and actions.
- **Interactive Skills Matrix**: Real-time search across 16 competencies with deep-dive modals.
- **Technical Co-Head (CABSSA)**: Official departmental club leadership and event highlights.
